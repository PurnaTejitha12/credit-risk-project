FinWise Lending - Credit Risk Scoring System

FinWise Lending is an AI/ML project focused on building a credit risk scoring system for loan applications.

The project uses XGBoost to predict credit risk and SHAP to explain the factors influencing each prediction. A FastAPI backend and React frontend are used to provide the predictions through a simple web application.

Technologies
Python
XGBoost
SHAP
FastAPI
React
Goal

To provide a credit risk score, classify applicants into Low, Medium, or High Risk, and explain the key factors behind each prediction.
